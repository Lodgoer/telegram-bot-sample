# telegram-bot-sample
 
A Telegram bot built with C# that welcomes new users to a group with a friendly, customizable greeting message.
 
## Features
 
- Detects when a new member joins the chat
- Sends an automated welcome message
- Message text and behavior can be customized per group
## Tech Stack
 
- C# / .NET
- Telegram Bot API
## Getting Started
 
1. Clone the repo and open `TelegramBotSample.sln` in Visual Studio
2. Create a bot via [@BotFather](https://t.me/BotFather) on Telegram and get your bot token
3. Add your token to the configuration (e.g. `appsettings.json` or environment variable — adjust based on how you're loading it)
4. Run the project and add the bot to a Telegram group as an admin
## Notes
 
This is a sample/starter project — a good base to extend with more commands or event handlers.
